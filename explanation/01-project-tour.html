From a manuscript to a submission-ready document.

Agent Paperpal automates a tedious but high-stakes task: adapting a research paper to a target journal’s formatting rules.

HomeSystem designStack masteryInterview playbook

Problem → outcome

Each journal encodes many rules: citation syntax, reference ordering, heading hierarchy, typography, figures, tables, and abstract constraints. Manual reformatting is repetitive and error-prone. This application turns journal rules into a structured input, combines LLM interpretation with exact programmatic checks, and generates a DOCX result plus a compliance explanation.

Two user experiences, one backend

A

Standalone web app

frontend/ is a React 19 single-page application built by Vite. App.jsx owns the page state: landing, configuration, pre-check, pipeline progress, results and errors. Components such as Upload, JournalSearch, SemiCustomPanel, ProgressScreen and ResultsScreen make each screen independently understandable.

B

Microsoft Word add-in

word-addin/ is another React/Vite client hosted as a secure Office taskpane. Office.js reads the active DOCX, sends it through the same API flow, then can replace the Word document with the returned DOCX. It avoids making a researcher leave the writing context.

The pipeline: judgment with guardrails

1

Extract and parse

Readers obtain text and media from PDF/DOCX. The parse agent turns manuscript content into structured information such as metadata, sections, citations and references.

2

Interpret rules

Built-in JSON holds known style rules. Standard mode loads it; semi-custom mode deep-merges overrides; full-custom mode converts a guideline document into the same rule shape and fills defaults.

3

Transform

The transform agent compares structured content with rules, makes citation/reference changes, and returns DOCX instructions. Dedicated Python writers produce journal-specific documents.

4

Validate

The validation agent produces a report; deterministic Python checks then cover measurable facts such as word count, DOI format, ordering, citation consistency, ampersand and et al. rules.

Why hybrid validation matters: LLMs are useful for ambiguous document structure and prose-level interpretation. They should not be the final authority for countable or regex-testable rules. Exact code makes the score reproducible.

What persists today

This is deliberately lightweight for a hackathon: rule JSON, temporary uploads, generated run folders, document metadata, jobs, and pipeline cache live locally/in memory. Cleanup removes old uploads and outputs. That makes the demo fast to build, but it means a process restart loses active job state and the service is not yet horizontally scalable.
