What is an API?

An API, or Application Programming Interface, is an agreed way for two software parts to communicate. The React frontend cannot run Python document-processing code itself. It sends an HTTP request to FastAPI; the backend performs the work and sends JSON back.

What is a route?

A route is a named entrance to a backend capability. The URL path and HTTP method identify it. FastAPI maps a route to a Python function using a decorator such as @app.post("/upload").

MethodMeaningExample
GETAsk for data without changing server data.GET /health
POSTSend data to create, begin, or process something.POST /upload, POST /format
Path parameterA value inside a URL that identifies one record./format/status/{job_id}
JSONA structured response that frontend code can safely read.{"job_id":"...","status":"processing"}

Why the new journal flow is agentic

Unknown journals are not trusted after one web result. The system searches candidates, ranks likely official sources, fetches the selected source, extracts a normalized rule draft, checks the schema and source coverage, then asks the user for approval. The AI handles research and ambiguous guidance; deterministic code enforces the trust boundary.

Important: user approval is a product guardrail. It stops a random search result from silently becoming journal policy for a formatting job.

Scoring: what trustworthy means

A deterministic check gives the same result for the same document and rules. Word counts, pattern matching, ordering and DOI syntax belong here. AI findings are still useful, but they should be labelled as suggestions rather than silently modifying a verified score.

How would you improve this project?

“First, I would make journal discovery evidence-backed: rank official sources, retain citations, extract rules with provenance, and require user approval. Second, I would calculate compliance from deterministic checks with visible coverage, and present AI judgement separately. Third, I would use a bounded critic that gets one targeted repair pass. For production, I would add PostgreSQL for durable jobs/audit data, object storage for documents, and queue-backed workers for long-running pipelines.”
